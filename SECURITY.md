# Security policy

Please do not report an unpatched vulnerability in a public issue or include sensitive documents in a public report.

This checkout does not yet have a configured GitHub repository or private reporting contact. Before announcing a public repository, maintainers must enable GitHub private vulnerability reporting or publish another monitored private channel. See [the security documentation](./docs/security.md) for the current security boundaries and file-processing limits.

The project has no published release or supported-version policy yet. Once releases begin, this file should list the versions receiving security fixes and link to the private reporting channel.
