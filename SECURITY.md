# Security policy

Please do not report an unpatched vulnerability in a public issue or include sensitive documents in a public report.

The public repository is [dukeofwest/universal-file-preview](https://github.com/dukeofwest/universal-file-preview). To report a vulnerability privately, use [GitHub's security advisory reporting page](https://github.com/dukeofwest/universal-file-preview/security/advisories/new) if private vulnerability reporting is enabled for the repository. If GitHub does not offer a private report form, do not post vulnerability details publicly; contact the repository maintainer through a private channel and ask for a secure reporting route. Do not include private documents in a report.

The project is in early development. Please report the affected package version. Security fixes are prepared for the current supported release; older releases are not guaranteed to receive backports. See [the security documentation](./docs/security.md) for the current security boundaries and file-processing limits.
